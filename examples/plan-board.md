# 计划板 · 计划看板插件

> 目标：把计划看板做成真正能用的工作台——能看清正在做什么、能批注、能否决，每条任务都写清楚做法和验收标准。

## P1 · 打通入口

- [x] 让左侧导航多出一个「计划板」图标，点开是一整页看板
  做法：向 sidebar.panellist 注册图标组件，向 main keyed slot 注册同 id 的整页面板。
  验收：点击图标能切到整页，刷新后仍在，禁用插件后消失。
- [x] 让会话头部的视图行里多出「计划板」标签页
  做法：向 conversation.view 注册一个 order 为 20 的视图项，与 Chat、Trajectory 并列。
  验收：视图行出现第三个标签，切换后渲染看板，控制台没有 slot entry crashed。
- [x] 把插件装进 desktop profile 并确认三个入口同时可用
  做法：plugin_manager install_bundle 链接本地目录，刷新页面后逐项验收。
  验收：左栏图标、整页、视图标签页三处都出现，且与本插件相关的控制台报错为空。

## P2 · 数据通道

- [x] 让面板读到工作区里的计划文件，并按分组渲染真实任务
  做法：客户端经 remote.workspaceFiles.read 读取 .dsh/plan-board.md，Host 侧另提供 /aboard json 作为兜底通道。
  验收：文件里的任务全部分组显示，计数与文件一致；文件缺失时显示空态而不是报错。
- [x] 让面板上的点击写回文件，支持打勾与改优先级
  做法：点击时调用 remote.commands.execute 执行 /aboard pick 或 /aboard prio，由 Host 改写文件后回传新数据。
  验收：点击后文件行尾出现 @选 或 @P0–@P3，面板计数立刻更新。
- [x] 让计划文件被外部改动时面板自动刷新
  做法：面板每 3 秒读一次文件版本，内容变化才更新界面；读取失败时降级到命令通道。
  验收：手动编辑文件后 3 秒内面板内容跟着变，且空闲轮询不产生会话记录。

## P3 · 模型侧

- [x] 给模型一个写板工具，写入前校验每条都是完整人话  @P0 @选
  做法：注册写板工具，每条必须包含标题、做法、验收三段，标题短于 20 字直接拒绝并要求改写。
  验收：提交「打通 API」这类简短条目会被工具退回，并返回明确的补全提示。
- [x] 给模型一个更新条目状态的工具  @P0 @选
  做法：工具支持 doing、done、dropped 三种状态切换，进行中时维护 @start 时间戳。
  验收：标记完成后文件里是 [x]；标记进行中时带 @start 且面板显示计时。
- [x] 让 /aboard 命令既能给人看也能给面板当接口  @P0 @选
  做法：Host 注册 aboard 命令，裸调用返回分组摘要，子命令支持 list、json、pick、prio、done、doing、drop、note、reorder。
  验收：/aboard 输出分组与计数；面板的读写在同一个命令上复用。

## P4 · 面板 v2

- [x] 正在做大卡：只显示当前进行中的那一条及其明细  @选
  做法：取第一条 [~] 条目，展示标题、做法、验收与 @start 算出的已进行时长；没有则显示本轮未开始。
  验收：标记进行中后，大卡显示明细与秒级计时。
- [x] 接入真实运行状态（运行中／空闲／等待批准）  @选
  做法：从会话快照读取 running，与文件里是否存在 [~] 条目交叉判断。
  验收：我在跑时显示运行中，空闲时显示空闲；在跑却没标进行中时出现黄色提醒。
- [x] 每条支持批注，批注写回文件并在面板展示  @选
  做法：条目内展开输入框，保存时调用 /aboard note，写入缩进的「批注：」行。
  验收：保存后文件出现批注行，面板条目下方显示批注原文，刷新后不丢失。
- [x] 每条支持「不要」，灰掉保留而不是删除  @选
  做法：调用 /aboard drop 把状态改为 [-] 并加 @弃 标签，可附原因批注。
  验收：点不要后条目变灰带删除线但仍可读，文件状态为 [-]；可再次点击恢复。
- [x] 条目详细度检查：缺验收或标题过短时标记「简略」  @选
  做法：面板按标题长度与验收字段判断，缺项挂灰色简略标记。
  验收：缺验收的条目显示简略标记，补齐后标记消失。
- [x] 完成的条目收进各分组的「已完成 n」折叠区  @选
  做法：分组内 [x] 条目默认折叠，点击展开。
  验收：默认只看到未完成条目，展开后能看到已完成内容。
- [x] 分组可折叠，组头显示子进度  @选
  做法：点击分组标题折叠或展开，组头渲染 done/total 与细进度条。
  验收：折叠后只保留组头，刷新页面后折叠状态保持。
- [x] 状态配色系统：未开始灰、进行中蓝、完成绿、废弃暗灰  @选
  做法：状态圈与左侧竖条使用主题 token 对应的四种颜色。
  验收：四种状态同屏可区分，暗色主题下对比度足够。
- [x] 顶部显示本轮目标摘要  @选
  做法：读取文件里的「> 目标：」行作为本轮目标展示。
  验收：修改目标行后，面板顶部文案跟着变化。
- [x] 键盘操作：上下移动、空格选择、数字键设优先级  @选
  做法：面板容器监听键盘事件，焦点条目高亮，按键映射到 pick 与 prio 命令。
  验收：不碰鼠标即可选中条目并设为 P1。
- [x] 搜索框：按关键词过滤任务  @选
  做法：输入即时过滤，命中条目保留，清空后恢复全部。
  验收：输入「批注」后只剩包含该词的条目。
- [x] 我的选择支持拖拽排序并写回文件  @选
  做法：拖动条目记录新顺序，松手调用 /aboard reorder 写入 @序 标签。
  验收：拖动后顺序变化，文件出现 @序=N，重开页面顺序保持。
- [x] 空态引导：第一次打开告诉用户怎么用  @选
  做法：没有任务时显示三步引导：让我拆任务、直接编辑文件、输入 /aboard。
  验收：空文件或空工作区下面板显示引导，而不是一片空白。

## P5 · 聊天卡片

- [x] 机器调用在聊天里折叠，不再刷 JSON  @选
  做法：接管 conversation.chat.commandview 的 aboard 行，带参数的调用渲染为不可见。
  验收：面板读写后聊天里不再出现 JSON 行，历史记录同样被折叠。
- [x] 裸 /aboard 显示摘要卡  @选
  做法：无参数调用时渲染一张卡片，展示分组摘要文本。
  验收：手打 /aboard 后聊天里出现一张卡片而不是原始文本。
- [x] 把摘要卡做成真卡片：分组标题、每组条数、进度条  @选
  做法：解析 Host 返回的结构化数据，渲染成分组列表与进度条。
  验收：摘要卡与左侧面板的视觉语言一致。
